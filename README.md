# Broadsides: Battleship vs AI

A medieval naval duel against an AI opponent, rendered in modern 3D.

**Play:** https://dpinchasi92.github.io/battleship/

> Work in progress. See [docs/PRD.md](docs/PRD.md) for the product plan and [BUGS.md](BUGS.md) for the bug log.

## Development

```bash
npm install
npm run dev        # local dev server
npm test           # unit tests
npm run lint
npm run typecheck
npm run build
```
